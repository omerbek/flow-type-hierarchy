# Görsel hiyerarşi

Ölçüm, birim ve durum bilgisinin hizasını ve boşluklarını değiştir.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.

## İlham kaynağı

Bu bağımsız sahne sentetik su istasyonu örnekleri kullanır. [Kaynak proje](https://github.com/pbakaus/impeccable).
