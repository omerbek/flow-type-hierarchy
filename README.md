# Flow Type Hierarchy / Görsel hiyerarşi

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/flow-type-hierarchy/).

Ölçüm, birim ve durum bilgisinin hizasını ve boşluklarını değiştir.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Gösterge başlığı
- Debi
- Durum

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Edit the heading, reading and status of an animated flow display.

Open [the live tool](https://omerbek.github.io/flow-type-hierarchy/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
